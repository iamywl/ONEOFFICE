## 2. 4대 축 핵심 강점 및 실무 마찰점 요약

### 1) 기능성 (Functionality: 4.78 / 5.00)
- **최고 강점**: HWPX 본문 내 엑셀 수식표 및 10대 도식화 인플레이스 삽입, (인) 앵커 0.1pt 자동 날인, 13대 MCP 도구 완결성.
- **마찰점**: HWPX 캔버스 내 다단/각주 렌더링 평탄화, 스프레드시트 비연속(Ctrl) 다중 셀 선택 보완 필요.

### 2) 기법성 (Techniques: 4.84 / 5.00)
- **최고 강점**: HarfRust 3-Pass 제약 레이아웃을 통한 0px 글자 넘침 방지, 크로마키 알파매팅을 통한 흰 배경 도장 누끼 제거.
- **마찰점**: 대형 수식 AST 파싱 에러 시 원인 툴팁 가시화 보강.

### 3) 기술성 (Technology: 4.85 / 5.00)
- **최고 강점**: Pure Rust 2024 `unsafe_code = "forbid"` Never-Crash 메모리 안전 보증, Hayro+Krilla 순수 Rust PDF 클린룸 엔진, FIPS 180-4 SHA-256 그리드 무결성, 적대적 퍼징 방어.
- **마찰점**: 대용량 배치 변환 시 진행률 스트리밍 프로토콜 추가 필요.

### 4) 사용성 및 인간공학 (Usability: 4.43 / 5.00)
- **최고 강점**: 1440px 풀 가로 뷰포트, 드래그 즉시 상태표시줄 5대 통계(합계, 평균 등) 실시간 표출, 글래스모피즘 라이트/다크 WCAG 4.5:1 이상 대비도.
- **마찰점 (핵심 개선 과제)**:
  1. `Tab` / `Shift+Tab` 키보드 중심 셀 순회 바인딩.
  2. HWPX 표 모서리 0px 공공 표준 스타일 프리셋.
  3. 스프레드시트 열 머리글 더블클릭 Auto-fit 및 회계 괄호 음수 포맷 `(1,000)`.
  4. 다자간 계약서용 `(인)` 앵커 순회 컨트롤러 (`[◀ 이전]`, `[다음 ▶]`).
  5. 슬라이드 `F5` 전면 프레젠테이션 슬라이드쇼 모드.
